# フェーズ移行時のルール

4フェーズ運用では、フェーズは大きな工程ではなく判断の区切りです。

## フェーズ区切りとみなす条件

1. 次の作業に必要な判断が揃っている
2. 残課題があれば短く明記されている
3. `Docs/` に残す価値がある情報だけが更新されている

## 区切り時にやること

1. 完了したことを短く要約する
2. 次のフェーズを明確にする
3. 必要なら `Docs/` を最小限更新する

## Git について

- コミットやプッシュは自動前提にしない
- 必要な場合だけ、ユーザーの明示依頼後に実施する
- メッセージ形式は [commit-message.md](./commit-message.md) を使う
